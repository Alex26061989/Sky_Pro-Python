# Автотесты Yougile (lesson 08)

## Описание

1.В этом проекте реализованы автотесты для методов работы с проектами в приложении Yougile.  
Используются библиотеки `pytest` и `requests`. Тесты покрывают следующие методы API:

- `[POST] /api-v2/projects` — создание проекта  
- `[PUT] /api-v2/projects/{id}` — обновление проекта  
- `[GET] /api-v2/projects/{id}` — получение информации о проекте  

Для каждого метода написаны *позитивные* и *негативные* тесты.

2.Установить переменную окружения с токеном:
    # Linux / Mac
export YOUGILE_TOKEN="ВАШ_ТОКЕН"

    # Windows
set YOUGILE_TOKEN="ВАШ_ТОКЕН"
⚠️ Внимание: токен не хранится в коде по соображениям безопасности.

3. Запустить тесты:    pytest -v
